# TIL 자동화 기능 명세
작성일: 2026-10-23
상태: 구현 전 검토용. 아래 명령·경로는 제안 인터페이스이며 현재 실행 가능한 프로그램이 아니다.

## 입력과 출력
| 항목 | 명세 |
| --- | --- |
| 대상 | 8113jsl-ui/TIL-Today-I-Learned- |
| 시간대 | Asia/Seoul |
| 입력 | 허용한 노션 페이지, 로컬 소스 파일, 선택적 전사 |
| 출력 | Markdown 학습 기록, 검토한 코드 스냅샷, README 링크, 검증 보고서 |
| 제외 | .git, .env, 키·인증 파일, 가상환경, 캐시, 대화 로그, 노트북 출력, 음성 원본 |
| 날짜 | lesson_date는 근거 없으면 null, recorded_date는 실제 작성일 |

## 데이터 계약
SourceRecord:
- source_id: 페이지 ID 또는 로컬 자료 ID와 상대 경로의 조합.
- source_type: notion / code / note / transcript.
- content_hash: 정규화한 UTF-8 본문의 SHA-256.
- fetched_at: 시간대 포함 수집 시각.
- lesson_date: 확인된 YYYY-MM-DD 또는 null.
- date_evidence: 제목·본문·사용자 확인 중 근거 위치.
- access_status: available / denied / unavailable / partial.
- visibility: private_input / publishable_excerpt / reviewed_code.
- locator: 페이지 블록, 파일+함수, 전사 구간. 로컬 절대경로는 공개본에 넣지 않는다.

NoteRecord:
- note_id, title, lesson_date, recorded_date, source_ids.
- code_refs: source_id, 상대 경로, 함수명, 파일 해시.
- claims: 문단별 source_id와 근거 위치.
- validation: syntax / unit / integration 각각 passed / failed / not_run 및 이유.
- status: collected → drafted → validated → ready → published.
- commit_sha: 게시 확인 전에는 null.

## 기능 요구사항
F01. 원본 폴더와 노션 페이지를 수정하지 않고 읽는다.
F02. 하위 페이지와 첨부가 누락되면 partial로 표시한다. 본문 수집 실패 시 글 생성을 중단한다.
F03. 가장 이른 확인 가능한 미게시 수업 날짜부터 처리한다. 날짜 미확인은 별도 검토 대기열에 둔다.
F04. 원자료에 없는 설명은 추가 학습으로 구분하고, 확인한 외부 출처를 연결한다.
F05. 코드 설명은 실제 함수와 연결한다. TODO·NotImplementedError는 완성 기능으로 표현하지 않는다.
F06. 노트북의 출력과 메타데이터는 공개 후보에서 제외한다. 코드 셀 안의 비밀값도 별도로 검사한다.
F07. 자료의 열람권한을 재배포권한으로 간주하지 않는다. 강의 원문 대신 자신의 요약과 필요한 코드 범위만 게시한다.
F08. 코드 스냅샷은 출처 폴더 별칭과 해시를 남기고, 팀 코드의 단독 저작·완성을 주장하지 않는다.
F09. allowlist에 포함된 산출물만 커밋한다. 원본 디렉터리의 git add 전체 실행은 금지한다.
F10. 원격 예상 HEAD를 비교한 후 fast-forward로 게시한다. 다른 변경이 있으면 재비교하고 재검증한다.
F11. 성공은 커밋 생성이 아니라 대상 브랜치의 SHA와 파일 내용 확인으로 판단한다.
F12. 누락 자료를 추측해 10개를 채우지 않는다. 자동 날짜 변경·빈 커밋·과거 날짜 조작은 하지 않는다.

## 제안 명령
- collect --source local|notion|transcript: 자료 목록과 접근 결과.
- draft --lesson ID: 출처가 연결된 Markdown 초안.
- validate --batch ID: 검사별 결과와 차단 사유.
- publish --batch ID --expected-head SHA: 검증된 파일만 게시.
- resume --batch ID: 원격과 기록을 대조해 미완료 단계만 재개.
실제 구현 시 명령명은 변경 가능하지만 단계별 입력·출력 계약은 유지한다.

## 오류와 재시도
- 401/403/404: 권한 상태를 기록하고 해당 자료 중단. 로그인 우회 금지.
- 일시적 통신/제한 오류: 최대 3회 지수형 대기 후 실패 보고.
- 비밀값 의심: 값 자체는 로그에 출력하지 않고 파일·위치만 기록, 공개 차단.
- 날짜 충돌: 두 근거를 보존하고 사용자 확인 전 lesson_date를 확정하지 않음.
- 코드 실패: 실패를 숨기지 않음. 해설용 미완성 스냅샷은 그 상태를 명시하고 실행 완료로 표시하지 않음.
- 커밋 후 기록 실패: 원격 SHA와 산출물 해시로 복구, 같은 변경을 다시 커밋하지 않음.
- 게시 후 문제: 과거 이력 강제 변경 대신 수정 커밋 또는 revert로 복구.

## 수용 기준
| 시나리오 | 기대 결과 |
| --- | --- |
| 같은 자료를 두 번 처리 | 두 번째 게시 변경 0개 |
| 같은 제목, 다른 원본 | source_id로 구분 |
| 파일 하나 수정 | 관련 글만 수정 후보 |
| 수업 날짜 없음 | 정리일만 표시, 수업일 추측 금지 |
| 접근 불가 노션 | 읽었다는 설명 없이 차단 사유 |
| API 키가 포함된 셀 | 출력값 노출 없이 게시 차단 |
| NotImplementedError 존재 | 미완성 표시, 실행 성공 주장 없음 |
| 원격 동시 변경 | 강제 갱신 없이 재비교 |
| 게시 중단 후 재개 | 중복 커밋 없음 |
| 10개 요청, 유효 변경 6개 | 6개와 부족 사유 보고 |
| 실제 API 테스트 미실행 | integration=not_run 및 이유 |

## 오늘 작업의 검증 범위
선별한 Python 소스는 AST 문법 검사를 수행했다. API 호출과 PDF 전체 처리의 통합 실행은 하지 않았다. 노션 본문·녹음 전사는 아직 확보하지 못했다. 이번 게시물은 로컬 코드 관찰과 자동화 설계 기록이며, 확인되지 않은 수업 날짜나 강의 내용을 주장하지 않는다.
