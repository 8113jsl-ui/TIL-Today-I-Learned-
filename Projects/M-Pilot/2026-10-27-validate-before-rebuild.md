# 색인을 지우기 전에 참조를 검증하기

정리일: 2026-10-27

## 확인한 자료

- `mpilot-handoff/mpilot-handoff/code/feature-vectordb-rebuild-index/mpilot/db/vectordb.py: rebuild_search_index`

위 경로는 제공받은 로컬 폴더 기준이다. 현재 프로젝트와 기능별 인계본을 구분하며, 인계본의 병합 여부는 확인하지 않았다.

## 코드에서 확인한 내용

인계 구현은 문서 ID 중복과 고객 절차 참조를 먼저 검사한다. 참조 문서가 실제 매뉴얼 본문인지, 같은 설비인지 확인한 뒤 두 컬렉션을 비우고 다시 쓴다.

## 배운 점

존재하는 ID라는 조건만으로는 부족하다. 코드 표 행을 절차로 잘못 참조하거나 다른 설비의 매뉴얼을 연결한 경우도 걸러야 한다. 검증을 삭제 전에 두면 잘못된 입력 때문에 기존 색인을 먼저 잃는 일을 피할 수 있다.

## 검증 범위와 주의점

이 구현은 원자 교체가 아니다. reset 이후 임베딩이나 저장이 실패하면 이전 색인을 유지한다고 보장할 수 없다. 입력 검증 단계의 보호와 전체 재생성 실패 복구를 구분해야 한다.

소스와 테스트 정의를 읽어 정리했다. 앱 실행, DB 연결, API 호출, 테스트 실행은 하지 않았으며 원본 프로젝트 파일을 수정하지 않았다. 팀 프로젝트 전체의 단독 구현을 주장하는 기록이 아니다.
