# 대화 저장과 상태 전이를 한 트랜잭션으로 묶기

정리일: 2026-10-27

## 확인한 자료

- `mpilot-handoff/mpilot-handoff/code/feature-rdb-chat-resolution/mpilot/db/rdb.py: save_chat_turn, _lock_open_support_case`

위 경로는 제공받은 로컬 폴더 기준이다. 현재 프로젝트와 기능별 인계본을 구분하며, 인계본의 병합 여부는 확인하지 않았다.

## 코드에서 확인한 내용

인계 구현의 save_chat_turn은 질문을 정리한 뒤 트랜잭션 안에서 신고 행을 잠그고 상태를 확인한다. 대화를 삽입하고, 접수 상태였다면 조치 중으로 바꾼다.

## 배운 점

대화만 저장되거나 상태만 바뀌는 중간 결과를 피하려는 구조다. 완료 처리가 동시에 들어오는 상황도 고려해 같은 신고 행의 상태 확인을 잠금과 연결한다.

## 검증 범위와 주의점

with_for_update가 적혀 있다는 사실만으로 모든 DB에서 동일한 동시성 동작이 검증된 것은 아니다. 실제 사용하는 DB의 트랜잭션 환경에서 확인해야 한다. 이번 기록은 소스 읽기 결과다.

소스와 테스트 정의를 읽어 정리했다. 앱 실행, DB 연결, API 호출, 테스트 실행은 하지 않았으며 원본 프로젝트 파일을 수정하지 않았다. 팀 프로젝트 전체의 단독 구현을 주장하는 기록이 아니다.

## 복습 질문

대화 삽입 후 상태 갱신이 실패했을 때 기대하는 DB 상태를 적기.
