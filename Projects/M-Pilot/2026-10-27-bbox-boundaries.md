# 좌표 검증에서 등호 경계를 확인하기

정리일: 2026-10-27

## 확인한 자료

- `m-pilot/mpilot/db/parser.py: RawTable._check_bbox_order`
- `m-pilot/tests/test_parser_types.py: test_raw_table_bbox_allows_equal_coordinates`

위 경로는 제공받은 로컬 폴더 기준이다. 현재 프로젝트와 기능별 인계본을 구분하며, 인계본의 병합 여부는 확인하지 않았다.

## 코드에서 확인한 내용

bbox 검증은 x0 > x1 또는 top > bottom이면 오류를 낸다. x0 == x1 또는 top == bottom은 현재 계약에서 허용한다. 테스트에도 폭과 높이가 0인 좌표를 허용하는 사례가 있다.

## 배운 점

‘좌표가 정상’이라는 문장은 충분히 구체적이지 않다. 뒤집히지 않았다는 조건과 실제 면적이 있다는 조건은 다르다. 이 코드의 검증 범위는 좌표 순서이며, 실제 표로 쓸 수 있는지는 별도 판단이다.

## 검증 범위와 주의점

SDD 예시표에는 정상 좌표, 뒤집힌 좌표, 같은 좌표를 각각 넣어야 한다. 유효한 PDF 페이지 영역 안에 들어오는지까지 이 검증이 보장한다고 설명하면 안 된다.

소스와 테스트 정의를 읽어 정리했다. 앱 실행, DB 연결, API 호출, 테스트 실행은 하지 않았으며 원본 프로젝트 파일을 수정하지 않았다. 팀 프로젝트 전체의 단독 구현을 주장하는 기록이 아니다.
