# Kubernetes가 관리하는 것

학습일: 2026-08-28

수업에서 Docker와 함께 Kubernetes라는 이름을 배웠다. 컨테이너를 실행하는 것과 여러 컨테이너의 운영 상태를 관리하는 일을 구분해 정리했다.

## 원하는 상태를 선언하기

Kubernetes는 컨테이너화된 애플리케이션의 배포와 운영을 관리하는 플랫폼이다. 원하는 상태를 선언하면 실제 상태가 그에 맞도록 조정하는 방식으로 동작한다.

애플리케이션을 여러 개 실행하도록 설정했다면 일부가 실패했을 때 원하는 개수를 유지하도록 복구를 시도할 수 있다. 서비스 연결과 부하 분산, 배포 갱신 등을 위한 기능도 제공한다.

## 모든 문제를 해결해 주지는 않는다

| 관리할 수 있는 영역 | 별도로 설계할 영역 |
| --- | --- |
| 실행할 워크로드 배치 | 애플리케이션 업무 로직 |
| 원하는 실행 상태 유지 | 잘못된 계산과 데이터 처리 |
| 배포와 서비스 연결 | 데이터 백업과 복구 정책 |

어디까지 자동화되는지는 구성에 따라 달라진다. 프로그램 자체에 같은 오류가 있다면 재시작만으로 해결되지 않을 수 있다.

## 도입 전에 생각할 점

작은 실습 프로젝트에도 반드시 필요한 것은 아니다. 운영할 구성 요소와 복구·확장 요구사항, 관리 부담을 함께 검토해야 한다.

## 복습한 내용

Docker와 Kubernetes를 같은 도구로 외우지 않기로 했다. 컨테이너 실행 환경을 이해한 다음 운영 상태를 지속적으로 관리해야 하는 이유와 연결해서 공부하겠다.
