# 클라우드에서도 서버와 운영은 남는다

학습일: 2026-08-28

수업에서 AWS, NCP, GCP 등 클라우드 서비스를 접했다. 클라우드를 사용하면 서버가 없어지는 것처럼 생각하기 쉬운데 필요한 컴퓨팅 자원을 서비스로 이용하는 방식에 가깝다.

## 어떤 자원을 이용하는가

클라우드에서는 컴퓨팅, 저장소, 데이터베이스 같은 자원을 필요에 따라 이용할 수 있다. 직접 장비를 구매하고 설치하는 방식과 비교해 자원 준비와 확장 방법이 달라진다.

| 필요한 기능 | 검토할 자원 |
| --- | --- |
| API 실행 | 컴퓨팅 환경 |
| 이미지·첨부파일 보관 | 저장소 |
| 사용자·업무 데이터 관리 | 데이터베이스 |
| 외부 연결 | 네트워크 구성 |

표는 특정 업체의 상품 추천이 아닌 복습용 예시다.

## 운영 책임 확인하기

관리형 서비스를 사용하면 일부 운영 작업을 서비스 제공자가 맡을 수 있다. 그래도 애플리케이션 설정, 데이터 접근 권한, 사용량 확인처럼 사용자가 관리할 부분이 남는다. 어떤 일을 누가 맡는지는 서비스에 따라 다르다.

필기에 적은 국내 서비스가 더 싸다는 설명도 일반화하지 않기로 했다. 지역, 자원 크기, 사용 시간, 저장량, 데이터 전송 조건을 함께 비교해야 한다.

## 복습한 내용

업체 이름보다 필요한 기능과 운영 방식을 기준으로 선택해야 한다. 실습에서도 자원을 만든 뒤 어디에 쓰이는지, 언제 종료할지까지 이해하고 사용하겠다.
