## 도구의 역할

필기에 등장한 개발 도구를 같은 종류로 묶기보다 편집·명령 실행·코드 실행이라는 역할로 구분한다.

| 도구 또는 개념 | 주요 역할 |
| --- | --- |
| 코드 에디터 | 소스 파일 작성과 수정 |
| IDE | 편집·실행·디버깅 등 개발 기능을 통합 |
| 터미널 | 셸과 상호작용하는 창 |
| 셸 | 명령을 해석하고 프로그램 실행 |
| Python 인터프리터 | Python 코드를 실행 |
| 노트북 | 코드·결과·설명을 셀 단위로 기록 |

VS Code에는 통합 터미널이 있지만, 편집 창과 터미널은 역할이 다르다. Python 확장 기능과 실제 Python 인터프리터도 구분해야 한다. [VS Code 시작 안내](https://code.visualstudio.com/docs/introvideos/basics)

## 실행 전에 확인하기

```powershell
python --version
python -c "import sys; print(sys.executable)"
```

첫 명령은 버전을, 두 번째는 실제 실행 파일 위치를 확인한다. 에디터가 선택한 인터프리터와 터미널의 인터프리터가 다르면 한쪽에서 설치한 패키지를 다른 쪽에서 찾지 못할 수 있다.

## 실행 위치와 상태

상대 경로는 현재 작업 디렉터리를 기준으로 해석된다. 파일이 보인다는 이유만으로 터미널에서도 같은 위치에 있다고 가정하지 않는다.

노트북에서는 셀을 실행한 순서에 따라 메모리에 남은 변수가 달라질 수 있다. 제출 전에 커널을 재시작하고 위에서부터 실행하면 숨은 상태 의존성을 찾는 데 도움이 된다.

8월 26일 필기의 터미널 단축키도 함께 정리한다. 위쪽 방향키는 보통 이전 명령을 불러오고, Ctrl+C는 실행 중인 프로그램에 중단 신호를 보낸다. 동작은 프로그램과 셸에 따라 달라질 수 있다.
