# 목업과 실제 동작을 구분하기

학습일: 2026-08-27

수업 필기에 목업을 '가짜'라고 적었다. 복습하면서 무엇을 확인하기 위해 실제 기능을 대신하는지 생각해 보았다.

## 목업으로 확인할 수 있는 것

화면 목업은 배치와 정보의 우선순위, 입력 흐름을 검토하는 데 사용할 수 있다. 할 일 세 개를 고정해서 보여 주면 목록이 읽기 쉬운지 논의할 수 있다.

하지만 그 화면만으로 저장 기능이나 사용자별 데이터 분리가 구현됐다고 판단할 수는 없다. 버튼을 눌렀을 때 화면만 바뀌는 것과 서버에 데이터가 저장되는 것은 다르다.

## 단계별 확인 예시

아래는 수업 내용을 바탕으로 구성한 복습용 구분이다.

| 단계 | 확인 대상 |
| --- | --- |
| 고정 데이터를 넣은 화면 | 배치와 표시 항목 |
| 샘플 응답을 연결한 화면 | 로딩·성공·실패 상태 |
| 실제 API를 연결한 화면 | 요청과 응답의 연결 |
| 저장소까지 연결한 기능 | 다시 조회했을 때 데이터 유지 |

샘플 데이터는 실제 사용자 데이터나 실제 측정 결과처럼 표시하지 않는다. 시연할 때도 화면 예시인지 저장까지 구현된 기능인지 구분해 설명한다.

## 복습한 내용

목업은 구현 전에 의견을 모으는 데 유용하다. 보기 좋은 화면을 완성한 것과 서비스 기능을 완성한 것은 각각 다른 확인이 필요하다.
