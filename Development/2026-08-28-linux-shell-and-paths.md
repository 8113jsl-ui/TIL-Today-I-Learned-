# Linux와 셸, 경로의 기본 개념

학습일: 2026-08-28

수업에서 서버 기술로 Linux와 셸 스크립트를 접했다. 명령어를 외우기 전에 운영체제와 셸이 맡는 역할을 구분했다.

## Linux와 셸

일상적으로 Linux라고 부르는 운영체제 환경에는 커널과 여러 도구가 포함된다. Ubuntu는 Linux 배포판의 한 예다. 셸은 사용자의 명령을 해석하고 프로그램 실행을 연결하는 역할을 한다.

터미널은 명령을 입력하고 출력을 보는 인터페이스다. 셸과 터미널을 비슷한 뜻으로 말하기도 하지만 같은 구성 요소는 아니다.

## 경로부터 확인하기

| 명령 | 기본 목적 |
| --- | --- |
| pwd | 현재 작업 디렉터리 확인 |
| ls | 디렉터리 내용 확인 |
| cd | 작업 디렉터리 이동 |

Linux의 절대 경로는 루트 디렉터리인 /에서 시작한다. 상대 경로는 현재 작업 디렉터리를 기준으로 해석한다. 같은 상대 경로도 어디에서 실행하는지에 따라 대상이 달라진다.

## 셸 스크립트로 연결하기

반복되는 명령을 파일에 정리하면 셸 스크립트로 실행할 수 있다. 작업 위치 확인, 프로그램 실행, 결과 확인처럼 반복되는 흐름을 정리하는 데 사용할 수 있다.

명령을 묶었다는 사실만으로 안전하게 자동화되는 것은 아니다. 실행 위치와 실패했을 때의 처리를 함께 생각해야 한다.

## 복습한 내용

서버에서 명령을 실행하기 전에 현재 위치와 대상을 확인하는 습관부터 들이겠다. 명령어 한 줄의 의미를 알고 연결해야 자동화 결과도 설명할 수 있다.
