# 디렉터리 트리의 노드와 연결

학습일: 2026-09-08

수업에서 디렉터리를 계층 구조로 정리하고 노드와 간선이라는 용어를 배웠다. 앞서 정리한 경로 명령어에서 더 나아가 폴더 관계 자체를 복습했다.

## 트리로 표현하기

복습용 프로젝트 구조를 생각해 보았다.

```text
project/
├── src/
│   └── app.py
└── docs/
    └── notes.md
```

project는 src와 docs의 부모이고 두 디렉터리는 형제 관계다. 이런 그림에서 항목은 노드, 부모와 자식을 잇는 관계는 간선으로 표현할 수 있다.

## 모든 노드가 IP 주소는 아니다

트리는 관계를 표현하는 자료구조다. 디렉터리 트리의 각 노드에 IP 주소가 필요하지는 않다. 네트워크 장비의 연결과 파일의 포함 관계는 서로 다른 대상을 모델링한 것이다.

파일 시스템에는 링크 등 더 복잡한 요소도 있지만 처음에는 부모와 자식의 포함 관계를 기준으로 이해하면 된다.

## 복습한 내용

경로는 계층 안에서 대상을 찾는 표현이다. 루트부터 따라가는 경로와 현재 위치를 기준으로 하는 경로를 구분하고, 트리라는 용어를 실제 네트워크 주소와 혼동하지 않겠다.
