# CPU·RAM·저장장치의 역할 구분

학습일: 2026-08-30

필기에 입력, RAM 저장, CPU 계산, 메모리 저장, 출력의 흐름을 적었다. 여기서 실행 중 사용하는 메모리와 파일을 보관하는 저장장치를 구분해야 한다.

## 역할별로 보기

| 구성 요소 | 기본 역할 |
| --- | --- |
| CPU | 명령 실행과 연산 |
| RAM | 실행 중인 프로그램과 데이터를 위한 작업 공간 |
| SSD·HDD | 파일과 프로그램 등을 지속적으로 보관 |

일반적인 RAM은 전원이 끊기면 내용이 유지되지 않는다. 반면 SSD나 HDD는 전원이 꺼져도 데이터를 보관하는 비휘발성 저장장치다.

## 할 일 앱의 예시

입력한 제목을 변수에 넣었다고 파일에 저장된 것은 아니다. 프로그램을 종료한 뒤에도 남겨야 한다면 파일이나 영속적인 데이터베이스에 기록하는 과정이 필요하다.

또한 데이터베이스라는 말 자체가 특정 하드웨어를 뜻하지는 않는다. 데이터베이스도 메모리를 활용하며, 설정에 따라 파일에 데이터를 보관할 수 있다.

## 복습한 내용

입력 → 처리 → 저장 → 출력은 이해를 위한 단순화다. 실제 프로그램은 읽기와 쓰기를 여러 번 반복한다. 변수에 값이 있다는 것과 다시 실행해도 값이 남는다는 것을 구분하겠다.
