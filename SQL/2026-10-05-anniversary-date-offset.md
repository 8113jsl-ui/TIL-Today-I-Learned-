# 기념일의 더하는 날짜 수 정하기

복습 정리일: 2026-10-05 (원래 수업일이 아님)

도서 주문 SQL 실습을 작은 가상 데이터로 재구성했다. 아래 쿼리는 **SQLite용**이며, 원본 MySQL 문법과의 차이를 구분한다.

## 실행 예제

```sql
SELECT DATE('2026-10-01','+1000 days') AS after_1000, DATE('2026-10-01','+999 days') AS day_1000;
```

예상 결과(행 배열): `[["2029-06-27","2029-06-26"]]`

출간일에서 1,000일 후와 출간일을 1일째로 세는 1,000일째는 하루 차이가 난다. 쿼리를 작성하기 전에 행사 문구가 어느 의미인지 정해야 한다.

## 기준을 문서로 남기기

원본은 출간일에 1,000일을 더한다. 복습에서는 두 규칙을 함께 계산해 차이를 드러냈다. 달력을 직접 월별로 계산하는 대신 날짜 함수를 사용하면 월 길이와 윤년을 반영할 수 있다. 결과 날짜가 있다고 실제 행사 일정이 확정되는 것은 아니다.
