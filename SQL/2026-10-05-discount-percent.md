# 할인율을 계산할 때 100으로 나누기

복습 정리일: 2026-10-05 (원래 수업일이 아님)

도서 주문 SQL 실습을 작은 가상 데이터로 재구성했다. 아래 쿼리는 **SQLite용**이며, 원본 MySQL 문법과의 차이를 구분한다.

## 실행 예제

```sql
SELECT 19900*(100-15)/100.0 AS discounted, CAST((19900*(100-15)/100.0)/100 AS INTEGER)*100 AS cut_to_hundred;
```

예상 결과(행 배열): `[[16915,16900]]`

19,900원의 15% 할인가는 16,915원이고 백 원 미만을 버리면 16,900원이다. 두 단계의 결과를 나누어 확인했다.

## 절사 규칙의 전제

예제는 음수가 아닌 가격과 0~100 범위의 할인율을 가정한다. SQLite의 정수 변환으로 절사를 표현했으며 원본 MySQL의 TRUNCATE를 실행한 것은 아니다. 실제 금액 계산은 자료형과 반올림·절사 시점을 업무 규칙에 맞게 정해야 한다.
