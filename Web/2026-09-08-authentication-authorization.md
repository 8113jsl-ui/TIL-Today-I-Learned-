# 인증과 인가를 구분하기

학습일: 2026-09-08

회원가입 프로그램 필기에 인증과 인가를 적었다. 인증은 누구인지 확인하는 과정이고, 인가는 그 주체가 해당 작업을 해도 되는지 판단하는 과정이다.

## 로그인과 접근 권한

| 상황 | 구분 |
| --- | --- |
| 로그인 자격 증명을 확인 | 인증 |
| 자신의 할 일만 수정하도록 검사 | 인가 |
| 관리자만 사용자 관리 화면에 접근 | 인가 |

로그인에 성공했다고 모든 데이터에 접근할 수 있는 것은 아니다. URL의 번호를 다른 사람의 데이터 번호로 바꾸는 경우에도 서버가 권한을 확인해야 한다.

## 화면에서 숨기는 것만으로 부족하다

수정 버튼을 화면에서 감추더라도 API 요청을 직접 보낼 수 있다. 권한 검사는 서버에서 요청마다 수행해야 한다. 허용한 경우만 접근하게 하는 방식과 필요한 최소 권한을 부여하는 원칙도 함께 생각한다.

## 복습한 내용

회원가입은 계정을 등록하는 절차이며 그 자체를 인증이나 인가의 정의로 삼으면 안 된다. 서비스를 만들 때 '누구인가'와 '무엇을 해도 되는가'를 별개의 질문으로 점검하겠다.
