# 할 일 앱으로 구분하는 프론트엔드와 백엔드

학습일: 2026-08-27

수업에서 프론트엔드, 백엔드, 데이터베이스의 역할을 배웠다. 할 일 앱에서 사용자가 추가 버튼을 누르는 상황을 기준으로 정리했다.

## 각 부분이 맡는 일

| 구분 | 역할 | 할 일 앱의 예시 |
| --- | --- | --- |
| 프론트엔드 | 사용자 입력과 화면 표시 | 제목 입력, 저장 중 표시, 목록 갱신 |
| 백엔드 | 요청 검증과 업무 처리 | 제목 검사, 사용자 권한 확인, 저장 요청 |
| 데이터베이스 | 데이터 저장과 조회 | 할 일의 제목·완료 여부 보관 |

프론트엔드는 디자인만 담당하는 것이 아니다. 입력 이벤트를 처리하고, 요청 상태와 오류를 사용자에게 전달하는 일도 포함한다. 백엔드도 데이터베이스를 그대로 보여 주는 역할에 그치지 않는다.

## 저장 버튼을 누르면

복습용으로 생각한 처리 순서는 다음과 같다.

1. 브라우저가 사용자가 입력한 제목을 읽는다.
2. 서버에 할 일 생성 요청을 보낸다.
3. 서버가 입력과 권한을 검사한다.
4. 데이터베이스에 저장하고 결과를 응답한다.
5. 브라우저가 결과에 맞춰 목록이나 오류 메시지를 보여 준다.

브라우저에서 빈 제목을 막더라도 서버에서 다시 검사해야 한다. 화면을 거치지 않고도 서버에 요청할 수 있기 때문이다.

## 언어와 역할을 혼동하지 않기

HTML은 문서 구조, CSS는 표현, JavaScript는 브라우저의 동작을 구현할 때 사용한다. HTTP는 통신 프로토콜이므로 HTML과 구분해야 한다.

Python과 Flask로 백엔드를 만들 수 있지만, 특정 언어 하나가 곧 프론트엔드나 백엔드를 뜻하는 것은 아니다. '어디에서 실행되고 어떤 책임을 맡는가'를 기준으로 이해하는 것이 더 정확하다.
