# HTTP 상태 코드와 통신 실패 구분

학습일: 2026-09-08

수업에서 403과 404를 배웠다. 오류 상태 코드도 서버가 보낸 HTTP 응답이며, 아예 응답을 받지 못한 상황과는 구분해야 한다.

## 코드의 범주

| 범위 | 큰 의미 |
| --- | --- |
| 2xx | 성공 |
| 3xx | 리다이렉션 등 |
| 4xx | 요청과 관련된 오류 |
| 5xx | 서버 오류 |

200은 성공, 201은 생성, 204는 응답 본문이 없는 성공을 나타낸다. 모든 성공 응답에 JSON 본문이 있다고 가정하면 안 된다.

## 401·403·404

401은 유효한 인증 자격 증명이 없음을 나타낸다. 403은 서버가 요청을 이해했지만 수행을 거부하는 경우다. 404는 요청한 자원을 찾을 수 없다는 의미이며 자원 존재를 숨기기 위해 쓰이기도 한다.

반면 연결 실패나 시간 초과에서는 사용할 수 있는 HTTP 상태 코드를 받지 못할 수 있다. 이 경우를 500 응답과 같은 것으로 취급하지 않는다.

## 복습한 내용

문제를 확인할 때 상태 코드, 응답 내용, 서버 로그를 함께 보겠다. 코드 하나만으로 모든 원인을 단정하지 않고, 응답을 받은 오류인지 통신 자체의 실패인지 먼저 구분한다.
