# URL의 경로·쿼리·프래그먼트

학습일: 2026-09-08

수업에서 URI와 URL, 물음표 뒤의 값을 배웠다. URI는 자원을 식별하는 개념이고 URL은 위치와 접근 방법을 나타내는 형태다. 웹 주소를 구성 요소별로 나누어 복습했다.

## 예시 주소 분석

https://example.com/notes?page=2#summary 는 설명을 위한 예시다.

| 부분 | 의미 |
| --- | --- |
| https | 스킴 |
| example.com | 호스트 |
| /notes | 경로 |
| page=2 | 쿼리 |
| summary | 프래그먼트 |

물음표는 쿼리의 시작을 나타낸다. 물음표를 넣는다고 GET 메서드가 되는 것은 아니다. 요청 메서드와 URL은 별개의 요소이며 POST 요청의 URL에도 쿼리가 있을 수 있다.

## 프래그먼트의 역할

# 뒤의 프래그먼트는 문서 안의 위치 등을 가리킨다. 일반적인 HTTP 요청에서는 서버에 전송되지 않고 클라이언트에서 처리된다.

경로에 긴 식별자가 있다고 그것을 무조건 파일 인코딩 값이라고 단정할 수도 없다. 서버가 정한 자원 식별 방식일 수 있다.

## 복습한 내용

URL을 문자열 전체로만 보지 않고 구성 요소로 나누면 라우팅과 검색 조건을 구분하기 쉽다. 민감한 값은 URL에 넣지 않도록 주의하겠다.
