# localhost와 0.0.0.0의 차이

학습일: 2026-08-27

필기에는 host를 0.0.0.0으로 지정하면 모든 주소를 허용한다고 적었다. 정확히는 서버가 어느 네트워크 인터페이스에서 연결을 받을지 정하는 바인딩 설정에 관한 설명이다.

## 주소를 구분하기

| 주소 | 의미 |
| --- | --- |
| 127.0.0.1 | 같은 컴퓨터 안에서 접근하는 IPv4 루프백 주소 |
| localhost | 일반적으로 루프백 주소로 해석되는 호스트 이름 |
| 0.0.0.0 | 서버 바인딩에서 모든 로컬 IPv4 인터페이스를 뜻하는 주소 |

다른 기기에서 접속할 때는 서버 컴퓨터의 실제 주소와 포트를 사용한다. 0.0.0.0을 다른 사람에게 전달할 접속 주소로 생각하면 안 된다.

## 바인딩과 접근 권한은 별개

모든 인터페이스에서 수신하도록 설정해도 방화벽과 네트워크 구성에 따라 접근 가능 여부가 달라진다. 사용자 인증이나 API 권한 검사가 자동으로 생기는 것도 아니다.

Flask 공식 문서에서도 외부에서 접근 가능한 개발 서버 설정을 설명하지만, 개발 서버를 실제 운영 서버로 사용하지 말라고 안내한다. 특히 디버거를 외부에 노출하는 설정은 피해야 한다.

## 복습한 내용

접속 문제는 서버 실행 여부, 수신 주소와 포트, 네트워크 경로, 접근 제어를 나누어 살펴본다. 모든 주소 허용이라는 한 문장으로 설명하면 서로 다른 설정을 혼동하기 쉽다.
