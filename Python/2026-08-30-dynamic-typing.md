# 동적 타이핑과 캡슐화는 다르다

학습일: 2026-08-30

필기에 Python이 타입을 내부에서 조정하는 것을 캡슐화라고 적었다. 복습하면서 동적 타이핑과 캡슐화를 구분했다.

## 이름과 객체의 타입

Python 객체에는 타입이 있다. 변수 이름은 객체를 가리키며 다른 타입의 객체에 다시 연결될 수 있다. 같은 객체의 타입이 자동으로 바뀐다는 뜻은 아니다.

```python
value = 3
assert type(value) is int
value = "3"
assert type(value) is str
assert int(value) + 2 == 5
```

문자열과 숫자를 섞으면 항상 알아서 변환해 주는 것도 아니다. 문자열 "3"에 정수 2를 더하려면 의도에 맞는 변환이 필요하다.

## 캡슐화와의 차이

캡슐화는 데이터와 동작을 묶고 외부에서 다루는 방식을 정하는 설계 개념이다. 변수 선언 시 타입을 생략할 수 있는 성질과는 다르다.

타입을 직접 선언하지 않는다고 타입을 몰라도 되는 것은 아니다. 입력값이 문자열인지 숫자인지 확인해야 연산 결과를 설명할 수 있다.
