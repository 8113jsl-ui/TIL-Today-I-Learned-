# 튜플의 불변성과 내부 객체

학습일: 2026-09-08

필기에 튜플을 한 번 정하면 바꿀 수 없는 리스트와 비슷한 자료형이라고 적었다. 튜플 자체의 요소 연결은 바꿀 수 없지만 내부에 변경 가능한 객체가 들어갈 수 있다는 점을 보완했다.

## 쉼표와 요소

```python
single = (10,)
assert isinstance(single, tuple)
assert isinstance((10), int)

point = (3, 4)
x, y = point
assert x + y == 7
```

요소가 하나인 튜플에는 쉼표가 필요하다. 괄호만으로는 튜플이 되지 않는다. 튜플은 함수와 함께만 쓰는 자료형도 아니다.

## 내부의 리스트

```python
record = ("study", [20])
record[1].append(30)
assert record == ("study", [20, 30])
```

위 예시는 튜플의 두 번째 요소를 다른 객체로 교체한 것이 아니라, 그 요소가 가리키는 리스트를 변경한 것이다. 튜플을 쓴다고 내부 데이터 전체가 깊게 고정되는 것은 아니다.

## 복습한 내용

불변성은 어떤 대상을 바꿀 수 없는지 정확히 따져야 한다. 변경을 금지하려는 데이터라면 튜플의 내부에 어떤 객체를 넣었는지도 확인하겠다.
