# 주석과 문자열, docstring의 차이

학습일: 2026-08-26 · 정리일: 2026-09-24

수업 필기.txt의 해당 날짜 구간을 바탕으로 정리했다. 용어 설명과 예제는 복습을 위해 보완했으며 수업 전체 기록은 아니다.

## 큰따옴표 세 개는 주석 기호가 아니다

필기의 삼중 따옴표 설명을 보완한다. Python에서 `#`는 주석을 시작한다. 삼중 따옴표는 여러 줄 문자열을 만드는 문법이다.

함수·클래스·모듈의 첫 문장에 놓인 문자열은 문서 문자열인 docstring으로 쓰인다. 위치와 목적을 구분해야 한다. [Python 함수와 문서 문자열](https://docs.python.org/3/tutorial/controlflow.html#documentation-strings)

```python
def remaining_minutes(total, used):
    """목표 시간에서 사용한 시간을 빼고, 최솟값을 0으로 제한한다."""
    # 목표를 초과했을 때 음수를 반환하지 않는다.
    return max(total - used, 0)

print(remaining_minutes(30, 40))
print(remaining_minutes.__doc__)
```

예상 출력:

```text
0
목표 시간에서 사용한 시간을 빼고, 최솟값을 0으로 제한한다.
```

## 무엇을 설명할 것인가

코드의 동작을 그대로 반복하는 설명보다 조건과 이유를 적는다. 예를 들어 ‘0을 반환한다’보다 ‘목표 초과 시 남은 시간을 음수로 표시하지 않는다’가 의도를 전달한다.

함수 설명에는 입력의 의미, 반환값, 실패 조건을 담을 수 있다. 주석이 코드와 달라지면 오히려 잘못된 판단을 유도하므로 구현 변경 시 함께 검토한다.

## 복습 기준

- `#` 주석과 문자열 리터럴을 구분한다.
- docstring은 정해진 위치에 놓인 문서 문자열이다.
- 주석이 있어도 코드가 정확하다는 보장은 없다.
- 설명과 실제 실행 결과를 함께 확인한다.
