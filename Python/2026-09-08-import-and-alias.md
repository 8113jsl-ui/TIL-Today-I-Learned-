# import와 as, 별칭의 의미

학습일: 2026-09-08

수업에서 import 모듈명 as 별칭 형식을 배웠다. 별칭은 다른 구현을 만드는 기능이 아니라 가져온 대상을 코드에서 다른 이름으로 참조하는 방법이다.

## 모듈과 함수 가져오기

```python
import math as m
from math import sqrt

assert m.sqrt(81) == 9.0
assert sqrt(81) == 9.0
```

첫 방식은 모듈에 별칭을 붙여 m.sqrt로 접근한다. 두 번째 방식은 sqrt라는 이름을 현재 이름 공간에 가져온다. 함수가 어디에서 왔는지 읽기 쉬운지도 고려해야 한다.

## 별표를 무조건 전체라고 외우지 않기

from 모듈 import *는 모듈의 공개 이름을 가져오는 문법이다. __all__ 설정 등의 영향을 받으며 모든 내부 이름을 무조건 가져오는 것은 아니다.

또한 *는 곱셈이나 인자 풀기 등 문맥에 따라 다른 의미로 쓰인다. 수업 필기의 '전체를 의미하는 기호'라는 설명은 모든 코드에 적용할 수 없다.

## 복습한 내용

별칭은 짧게 쓰는 편의 기능이지만 의미가 불분명한 이름을 남발하면 코드를 읽기 어려워진다. 이름 충돌과 출처를 함께 생각하며 import 방식을 선택하겠다.
