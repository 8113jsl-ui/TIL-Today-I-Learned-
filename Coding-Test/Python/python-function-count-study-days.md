# [Python 코딩테스트 기초 02] 목표 시간을 채운 날 세기 — 반복문과 return

원문: [Velog](https://velog.io/@8113jsl-ai/python-function-count-study-days)

파이썬 반복문을 연습할 겸, 공부 시간을 세는 간단한 문제를 준비했어요. 하루하루 기록한 시간 중에서 목표를 채운 날이 며칠인지 구해보려고 합니다.

이번 예제는 프로그래머스 기초 학습과 함께 연습할 수 있도록 별도로 구성했어요. 사이트에 있는 특정 문제의 풀이는 아닙니다.

## 목표를 채운 날을 세어볼까요?

날짜별 공부 시간 minutes와 하루 목표 target을 받아, 목표 이상 공부한 날의 수를 반환하는 solution 함수를 만들면 됩니다. minutes의 길이는 0~10,000이고, 각 시간과 target은 0~1,440 사이의 정수로 정할게요. 기록이 없는 빈 리스트도 들어올 수 있어요.

```python
minutes = [15, 40, 25, 40, 5]
target = 25
# 기대 반환값: 3
```

25분이 목표라면 40분, 25분, 40분 공부한 세 날이 해당해요. 같은 40분이어도 서로 다른 날이니 각각 세면 됩니다.

## 일단 하루씩 살펴보면 돼요

처음부터 짧게 쓰려고 하기보다는, 사람이 세는 순서대로 적어볼게요. 조건을 만족한 날의 수를 0으로 놓고, 하루씩 확인하면서 목표 이상이면 1을 더합니다.

```python
def solution(minutes, target):
    count = 0
    for minute in minutes:
        if minute >= target:
            count += 1
    return count
```

여기서 눈여겨볼 부분은 >=예요. 정확히 25분 공부한 날도 포함해야 하므로 >만 쓰면 그날이 빠지게 됩니다.

## print와 return은 어디에 쓰면 될까요?

print()는 화면에 값을 보여주고, return은 함수를 호출한 곳으로 값을 돌려줘요. 이번에는 계산 결과를 반환하는 함수를 만들고 있으니 return이 필요합니다. 화면에서 결과를 확인할 때는 이렇게 쓰면 돼요.

```python
result = solution([15, 40, 25, 40, 5], 25)
print(result)  # 3
```

return count의 들여쓰기도 확인해 주세요. 모든 날짜를 센 뒤에 반환해야 하므로 반복문 바깥에 둡니다. 반복문 안에 넣으면 날짜를 전부 살펴보기 전에 함수가 끝날 수 있어요.

## 아무 기록도 없다면요?

평범한 입력 외에 이런 경우도 함께 확인했어요. 아래 결과는 Python에서 검증했으며, 사이트 채점 기록은 아닙니다.

| 공부 시간 | 목표 | 결과 |
| --- | ---: | ---: |
| [15, 40, 25, 40, 5] | 25 | 3 |
| [] | 25 | 0 |
| [24, 25, 26] | 25 | 2 |
| [0, 0] | 0 | 2 |

빈 리스트에서는 반복문이 한 번도 실행되지 않아요. 처음 정해둔 count가 그대로 0이어서 별도 처리 없이도 결과가 나옵니다. 마지막 예시는 조금 낯설지만 목표가 0분이므로 기록된 두 날 모두 조건을 만족해요.

## 익숙해지면 이렇게 줄일 수도 있어요

```python
def solution(minutes, target):
    return sum(1 for minute in minutes if minute >= target)
```

목표를 채운 날마다 1을 만들어 더하는 제너레이터 표현식이에요. 결과 리스트를 따로 만들지는 않습니다. 아직 읽기 어렵다면 위의 반복문 버전으로 작성해도 충분해요.

두 코드 모두 날짜를 한 번씩 확인하므로 기록이 n개라면 시간 복잡도는 O(n), 입력 리스트를 제외한 추가 공간은 O(1)입니다. 이번 문제에서는 코드 길이보다 목표와 같은 값도 포함하는지, 끝까지 센 뒤 반환하는지를 확인하는 게 중요해요.
