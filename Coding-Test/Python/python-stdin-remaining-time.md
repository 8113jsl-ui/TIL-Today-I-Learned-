# [Python 코딩테스트 기초 01] 입력받은 시간으로 남은 공부 시간 계산하기

원문: [Velog](https://velog.io/@8113jsl-ai/python-stdin-remaining-time)

파이썬 입출력을 연습하려고 남은 공부 시간을 계산하는 작은 문제를 준비했어요. CodeUp 기초 학습과 함께 익힐 수 있는 내용이지만, 사이트의 특정 문제나 예제를 가져온 것은 아닙니다.

## 오늘 얼마나 더 공부하면 될까요?

하루 목표 시간 total과 이미 공부한 시간 used가 한 줄에 들어온다고 해볼게요. 두 값은 공백으로 구분된 0~1,000 사이의 정수이고, 입력 형식은 올바르다고 가정합니다.

우리가 출력할 것은 목표까지 남은 시간이에요. 이미 목표를 채웠거나 초과했다면 0을 출력하면 됩니다.

입력이 다음과 같다면,

```text
90 35
```

90분 중 35분을 공부했으니 남은 시간은 55분이에요.

```text
55
```

## 입력을 숫자로 바꾸는 것부터 시작해요

input()으로 읽은 내용은 문자열이에요. split()으로 두 값을 나눈 다음, map(int, ...)로 각각 정수로 바꿔줍니다. 그다음에는 목표 시간에서 공부한 시간을 빼면 돼요.

```python
total, used = map(int, input().split())
remaining = total - used

if remaining < 0:
    remaining = 0

print(remaining)
```

목표를 넘겨 공부했다면 뺄셈 결과가 음수가 되겠죠. 그럴 때만 remaining을 0으로 바꿔줍니다. 남은 공부 시간이 마이너스로 표시되지는 않도록 하는 거예요.

## 목표를 딱 채운 경우도 확인해요

네 가지 경우의 계산 결과를 Python으로 확인했어요. 특정 사이트에 제출해서 받은 채점 결과는 아닙니다.

| 목표 시간 | 공부한 시간 | 남은 시간 |
| ---: | ---: | ---: |
| 90 | 35 | 55 |
| 20 | 20 | 0 |
| 10 | 30 | 0 |
| 0 | 0 | 0 |

목표와 공부한 시간이 같으면 처음 뺄셈에서 이미 0이 나와요. 그래서 조건문에서 별도로 처리하지 않아도 됩니다. 둘 다 0인 경우도 같은 방식으로 계산할 수 있어요.

## max를 쓰면 조금 짧아져요

```python
total, used = map(int, input().split())
print(max(total - used, 0))
```

max()는 두 값 중 큰 값을 골라줘요. 남은 시간이 양수이면 그 값을, 음수이면 0을 선택하니 앞의 조건문과 같은 결과가 나옵니다.

처음에는 조건문 버전으로 흐름을 이해한 뒤 짧은 코드와 비교해보면 좋아요. 입력값 두 개만 다루므로 이 문제의 제한 안에서는 시간과 추가 공간을 모두 O(1)로 볼 수 있습니다.

마지막으로 출력에는 필요한 숫자만 남겨주세요. input() 안에 안내 문장을 넣으면 그 문장도 출력되어 자동 채점이 기대하는 결과와 달라질 수 있어요.
