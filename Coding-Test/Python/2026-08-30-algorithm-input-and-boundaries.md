# 알고리즘 문제는 입력 조건부터 읽기

학습일: 2026-08-30

수업에서 자료구조와 알고리즘을 공부하라는 이야기를 들었다. 복습용으로 공부 시간 중 목표 이상인 날을 세는 문제를 생각해 보았다.

## 문제를 작은 질문으로 나누기

먼저 입력의 형태와 범위, 필요한 출력, 예외적인 경우를 적는다. 값이 하나도 없을 수 있는지와 목표와 정확히 같은 값도 포함하는지를 확인해야 한다.

```python
minutes = [20, 30, 45]
target = 30
count = sum(1 for minute in minutes if minute >= target)
assert count == 2
assert sum(1 for minute in [] if minute >= target) == 0
```

위 코드는 수업 주제를 바탕으로 만든 복습용 예시다. 목표와 같은 30분도 포함하므로 비교 연산은 >가 아니라 >=다.

## 정확성과 효율성

각 값을 한 번씩 확인하므로 입력 개수에 비례해 비교 횟수가 늘어난다. 이런 관찰이 시간 복잡도를 생각하는 출발점이다.

정답 예시 한 개만 맞추기보다 빈 입력, 경계값, 모든 값이 조건을 만족하는 경우를 확인해야 한다. 코딩테스트 준비는 풀이를 외우는 것보다 조건을 정확하게 코드로 옮기는 연습으로 접근하겠다.
