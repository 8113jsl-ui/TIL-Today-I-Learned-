# 작은 언어 모델과 로컬 실행은 같은 말일까

학습일: 2026-09-11

수업에서 작은 언어 모델과 온디바이스 AI를 접했다. 모델 규모와 실행 위치는 서로 관련이 있지만 같은 개념은 아니다.

## 크기와 위치를 구분하기

작은 언어 모델은 대규모 모델에 비해 파라미터 수와 자원 요구량이 작은 모델을 가리킬 때 사용한다. 정확한 크기 경계가 하나로 고정된 용어는 아니다.

온디바이스 실행은 모델을 사용자 기기에서 실행하는 방식이다. 작은 모델도 클라우드에서 제공할 수 있고, 로컬 실행 가능 여부는 메모리와 연산 자원 등 조건에 따라 달라진다.

## 보안과 맞춤화도 따로 확인하기

로컬에서 추론하면 외부 전송을 줄일 수 있지만 앱의 로그, 동기화, 외부 도구 호출까지 자동으로 차단되는 것은 아니다. 실제 데이터 흐름을 확인해야 한다.

작다는 이유만으로 개인 맞춤 기능이 생기지도 않는다. 지시문, 검색 자료, 추가 학습 등 어떤 방법으로 업무에 맞출지 검토해야 한다.

## 복습한 내용

모델 이름보다 필요한 작업의 정확성, 지연시간, 메모리 사용량, 데이터 이동 경로를 비교하겠다. 작은 모델이 모든 상황에서 더 좋거나 더 안전하다고 단정하지 않겠다.
