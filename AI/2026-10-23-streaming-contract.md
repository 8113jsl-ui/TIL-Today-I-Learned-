# 스트리밍 조각과 누적 출력의 차이

정리일: 2026-10-23. 실제 수업일은 미확인이다.

## 자료 범위

사용자가 제공한 로컬 실습 코드에 대한 복습 기록이다. 전체 수업 노션은 접근하지 못했으므로 강의 본문과의 대조는 아직 하지 않았다. 아래 스냅샷은 원본의 일부이며 독립 실행 프로젝트가 아니다. 팀 실습 코드의 단독 작성이나 전체 완성을 주장하지 않는다.

- [desktop-chat-pdf/src/rag/generator.py](../examples/2026-10-23-code-reading/desktop-chat-pdf/src/rag/generator.py)

## 코드에서 확인한 흐름

answer의 반환 계약은 Iterator[str]다. 설명에는 모델 준비와 검색기·체인 연결, 매 yield마다 누적 답변을 내보내는 방식이 적혀 있다.

## 주의할 점

현재 함수는 NotImplementedError를 발생시킨다. 실제 스트리밍을 검증한 상태가 아니다. 조각만 출력하면 화면이 마지막 조각으로 덮일 수 있으므로 UI 계약에 맞춰 누적 여부를 정해야 한다.

## 직접 확인할 문제

조각 두 개가 도착할 때 첫 번째와 두 번째 화면 문자열을 적기.

## 검증 범위

첨부한 Python 파일의 AST 문법 검사를 통과했다. 라이브러리 의존성 설치·실제 API 호출·PDF 처리 통합 테스트는 하지 않았다. 설명에 적은 미구현 함수는 그대로 보존했다.
