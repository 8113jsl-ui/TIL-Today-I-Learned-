# 페이지 단위 분류가 검색에서 놓치는 것

정리일: 2026-10-23. 실제 수업일은 미확인이다.

## 자료 범위

사용자가 제공한 로컬 실습 코드에 대한 복습 기록이다. 전체 수업 노션은 접근하지 못했으므로 강의 본문과의 대조는 아직 하지 않았다. 아래 스냅샷은 원본의 일부이며 독립 실행 프로젝트가 아니다. 팀 실습 코드의 단독 작성이나 전체 완성을 주장하지 않는다.

- [course-chat-pdf/src/db/categories.py](../examples/2026-10-23-code-reading/course-chat-pdf/src/db/categories.py)

## 코드에서 확인한 흐름

다른 chat-pdf의 categories.py는 CATEGORY_NAMES, PAGE_CATEGORY_MAP, PAGE_ARTICLES로 주제·페이지·조항 표기를 연결한다. 페이지 하나에 주제 하나를 붙이는 방식이다.

## 주의할 점

원본 주석도 한 페이지에 여러 주제가 섞이면 일부 내용이 필터 검색에서 빠질 수 있다고 설명한다. PDF 인덱스와 인쇄 쪽 번호는 표지 때문에 다를 수 있으므로 +1만으로 항상 일치한다고 가정하지 않는다. 규정 자체의 최신성이나 법적 내용을 검증한 글은 아니다.

## 직접 확인할 문제

혼합 주제 페이지의 질문을 필터 검색과 전체 검색에서 비교하는 평가 항목 만들기.

## 검증 범위

첨부한 Python 파일의 AST 문법 검사를 통과했다. 라이브러리 의존성 설치·실제 API 호출·PDF 처리 통합 테스트는 하지 않았다. 설명에 적은 미구현 함수는 그대로 보존했다.
