# 컨텍스트와 학습, 장기 기억의 차이

학습일: 2026-09-11

수업 필기에 AI의 메모리를 컨텍스트라고 적었다. 비슷하게 느껴지지만 모델에 현재 제공되는 정보와 장기 저장, 모델 학습은 구분해야 한다.

## 세 가지를 나누어 보기

| 구분 | 핵심 |
| --- | --- |
| 컨텍스트 | 현재 응답을 만들 때 모델에 제공된 정보 |
| 외부 저장·검색 | 문서나 기록을 보관하고 필요한 내용을 다시 가져오는 기능 |
| 모델 학습 | 학습 절차를 통해 모델 파라미터를 조정하는 과정 |

대화에서 정정 내용을 알려 주었다고 모델의 파라미터가 즉시 업데이트되는 것은 아니다. 이전 내용을 다시 입력에 포함하면 해당 응답에 활용할 수 있다는 것과 구분한다.

## 컨텍스트에도 한계가 있다

컨텍스트 윈도는 한 번에 처리할 수 있는 토큰 범위와 관련된다. 구체적인 크기와 처리 방식은 모델과 서비스에 따라 다르다. 긴 대화의 모든 내용을 항상 그대로 사용할 수 있다고 가정하면 안 된다.

## 복습한 내용

중요한 조건은 문서로 남기고 작업 시 필요한 부분을 명확히 제공하겠다. 대화에 한 번 썼다는 사실보다 현재 모델이 어떤 정보를 전달받았는지 확인하는 것이 중요하다.
