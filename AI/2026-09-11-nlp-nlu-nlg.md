# 자연어와 NLP·NLU·NLG 구분하기

학습일: 2026-09-11

필기에는 자연어를 NLP라고 적었다. 자연어는 사람이 사용하는 언어이고, NLP는 자연어를 컴퓨터로 처리하는 기술과 연구 분야를 뜻한다.

## 용어별 초점

| 용어 | 초점 | 복습용 예시 |
| --- | --- | --- |
| NLP | 자연어 처리 전반 | 텍스트 분류, 번역, 요약 |
| NLU | 의미와 의도 파악 | 문의가 배송 문제인지 판단 |
| NLG | 언어 생성 | 처리 결과를 안내 문장으로 작성 |

NLU와 NLG는 NLP 안에서 이해와 생성이라는 관점으로 구분할 수 있다. 실제 시스템에서는 여러 기능이 결합된다.

## 고객 문의를 예로 들면

'배송이 아직 안 왔어요'라는 문장에서 의도를 파악하고 필요한 주문 정보를 찾은 뒤 안내 문장을 생성할 수 있다. 문장을 자연스럽게 생성하는 것과 실제 주문 상태를 정확히 확인하는 것은 다른 문제다.

## 복습한 내용

자연어를 다룬다는 이유만으로 시스템이 사람처럼 이해한다고 단정하지 않겠다. 서비스가 수행해야 하는 작업을 분류, 정보 추출, 생성처럼 구체적으로 나누어 보겠다.
