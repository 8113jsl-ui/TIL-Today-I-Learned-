# AI·ML·생성형 AI와 도메인 이해

학습일: 2026-08-25 · 정리일: 2026-09-24

수업 필기.txt의 해당 날짜 구간을 바탕으로 정리했다. 용어 설명과 예제는 복습을 위해 보완했으며 수업 전체 기록은 아니다.

## 용어를 구분하기

AI는 인식·추론·생성 등 지능적인 작업을 수행하는 기술을 포괄하는 말이다. 머신러닝은 데이터를 통해 모델의 동작을 학습하는 접근이다. 생성형 AI는 학습한 패턴을 바탕으로 문장·이미지 같은 콘텐츠를 생성한다.

머신러닝과 생성형 AI를 서로 완전히 별개인 기술로 나누면 안 된다. 생성형 AI에도 머신러닝이 사용된다. 또한 생성은 저장된 정답을 그대로 검색하는 것과 다르므로, 자연스러운 답변이 사실을 보장하지 않는다. [Google 머신러닝 입문](https://developers.google.com/machine-learning/intro-to-ml/what-is-ml)

| 구분 | 확인할 질문 | 예시 |
| --- | --- | --- |
| 분류 | 어느 범주에 속하는가? | 문의를 배송·결제·반품으로 분류 |
| 수치 예측 | 어떤 수치가 예상되는가? | 다음 주 주문량 추정 |
| 생성 | 어떤 결과물을 만들 것인가? | 문의에 대한 답변 초안 작성 |
| 서비스 | 사용자가 업무를 어떻게 끝내는가? | 문의 접수부터 답변 검토·발송까지 |

## 모델과 서비스의 차이

모델의 출력은 서비스의 일부다. 실제 서비스에는 입력 화면, 데이터 조회, 사용자 권한, 오류 처리, 결과 검증이 함께 필요하다. 모델이 답변을 만들었다고 고객 문의 업무 전체가 끝난 것은 아니다.

## 도메인 이해를 적용하기

필기의 ‘도메인 = 업무’는 출발점으로 유용하다. 업무의 용어뿐 아니라 규칙과 예외를 이해해야 한다. 반품 답변 서비스라면 반품 가능 기간, 상품 상태, 결제 수단별 환불 절차를 알아야 출력이 맞는지 판단할 수 있다.

먼저 업무 규칙을 적고, 필요한 데이터와 실패했을 때의 처리 방식을 정한 다음 모델의 역할을 배치한다. 모든 기능에 AI를 붙이기보다 확정적인 규칙으로 처리할 부분도 구분한다.
