# 실제 데이터와 예시 데이터를 구분하기

학습일: 2026-09-10

수업에서 설문 보고서를 만들 때 응답자 수와 방법론, 통계값을 명확히 적는 사례를 보았다. 생성한 예시 데이터와 실제 조사 결과는 반드시 구분해야 한다.

## 숫자가 있다고 근거가 되는 것은 아니다

보고서에 만족도나 평균이 표시되어도 입력 자료에 없는 수치를 만들어 넣었다면 실제 조사 결과가 아니다. 테스트용 데이터는 사용할 수 있지만 제목과 설명에 가상 자료임을 표시해야 한다.

| 구분 | 확인할 내용 |
| --- | --- |
| 실제 조사 | 조사 기간, 대상, 응답 수, 수집 방법 |
| 기존 자료 인용 | 출처, 발표 시점, 적용 범위 |
| 가상 데이터 | 생성 목적과 실제 측정값이 아니라는 설명 |

## 누락된 값 다루기

필요한 데이터가 없으면 확인되지 않았다고 표시하거나 추가 자료를 요청한다. 다른 업체의 숫자를 가져왔다면 우리 서비스에서 측정한 값처럼 쓰지 않는다.

통계를 계산할 때도 어떤 응답을 포함했는지, 결측값을 어떻게 다뤘는지 적어야 같은 결과를 다시 확인할 수 있다.

## 복습한 내용

그럴듯한 보고서보다 숫자의 출처와 계산 과정을 설명할 수 있는 보고서를 만들겠다. 데이터 생성은 연습에 도움이 되지만 사실을 대신할 수는 없다.
